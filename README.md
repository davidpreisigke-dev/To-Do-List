To Do List

Projeto de lista de tarefas desenvolvido com React e Vite.

Sobre o projeto

O To Do List e uma aplicacao simples para criar, visualizar, pesquisar, concluir e remover tarefas. O objetivo principal do projeto e praticar conceitos fundamentais do React, como componentes, props, estado e eventos.

Funcionalidades

- Criar novas tarefas
- Adicionar categoria para cada tarefa
- Pesquisar tarefas pelo titulo
- Marcar tarefas como concluidas
- Remover tarefas da lista
- Atualizar a interface automaticamente quando o estado muda

Tecnologias utilizadas

- React
- Vite
- JavaScript
- HTML
- CSS
- ESLint

 Conceitos e metodos praticados

React

- `useState` para controlar estados da aplicacao
- Componentizacao da interface
- Passagem de dados por `props`
- Renderizacao de listas com `map`
- Eventos com `onClick`, `onChange` e `onSubmit`
- Renderizacao condicional para aplicar estilos em tarefas concluidas

JavaScript

- `map` para percorrer e renderizar tarefas
- `filter` para remover e pesquisar tarefas
- `toLowerCase` para tornar a pesquisa mais flexivel
- `includes` para verificar se o texto pesquisado existe na tarefa
- Spread operator `...` para criar novas listas sem alterar diretamente o estado original
- Arrow functions

#CSS

- Estilizacao de componentes
- Uso de `display: flex`
- Organizacao visual dos itens da lista
- Estilizacao de botoes, inputs e containers


Aprendizados

Neste projeto foram praticados os fundamentos de uma aplicacao React: dividir a tela em componentes, controlar dados com estado, enviar funcoes entre componentes por props e atualizar a interface com base nas acoes do usuario.
